Privacy Router / 로컬 데모

라우트가 실행되기 전에 그 경로를 직접 살펴보세요.

FastAPI 화면을 통해 민감도, 필수 여부, 선택된 로컬 라우트를 직접 확인할 수 있습니다. 이 페이지는 데모 입력을 클라우드 모델로 보내지 않습니다.

● 로컬 개발

이 페이지는 로컬 개발 전용입니다. 발급된 클라이언트 키는 브라우저에 표시되며 이 브라우저 세션에만 저장됩니다.

01 / 접근

브라우저 API 키

이 키는 이 페이지가 라우터 데모 요청에 자동으로 첨부합니다. 키 발급은 dev 모드에서만 가능하며, serve 모드에서는 기존 키가 필요합니다.

02 / 검사

라우터 테스트

POST /api/demo/router

03 / 일괄 실행

로컬 데모 전체 실행

내장된 라우터 시나리오를 단일 PrivacyRouter 인스턴스로 순차 실행합니다. 각 case가 진행되는 동안 페이로드와 진행률이 화면에 그대로 표시됩니다.
