# I-003: vLLM Acceleration Analysis

## Summary
MRv2가 throughput 2x, concurrency scaling이 near-linear to 16x. ngram과 MRv2는 비호환.

## Key Insights

### 1. MRv2 = 최고 가성비
| Technique | Throughput Gain | Accuracy Impact |
|---|---|---|
| MRv2 | **+100%** | 0% |
| ngram speculative | +12% | 0% |
| prefix-caching | 0% (이미 활성) | 0% |

### 2. MRv2 + ngram 비호환 (vLLM 0.23.0)
둘 다 활성화하면 런타임 에러. 택 1.

### 3. Concurrency Scaling
```
E4B: 1x → 8x = 8x throughput (near-linear)
     8x → 16x = 1.26x (diminishing)
     16x → 24x = 1.0x (plateau, accuracy drops)
```

### 4. Accuracy는 concurrency와 무관 (until threshold)
- E4B: ≤16x = 74.2%, ≥24x = accuracy collapse
- E2B: ≤32x = 65% (정확도 유지 범위 더 넓음 — 모델이 작아서)

## Recommendation
| Setting | Value |
|---|---|
| MRv2 | on |
| Prefix caching | on |
| ngram | off (MRv2와 비호환) |
| Concurrency | 모델별 sweep 필요 |
