# I-001: Prompt Optimization Analysis

## Summary
E4B 모델에서 33개 프롬프트 variant를 테스트한 결과, **fewshot_v2**가 최고 성능 (88.2%)을 달성.

## Key Insights

### 1. Few-shot이 가장 큰 영향
| Approach | Accuracy | Delta |
|---|---|---|
| zeroshot (baseline) | ~65% | — |
| fewshot (5 examples) | 70.6% | +5.6%p |
| fewshot_v2 (+ rules) | 88.2% | +17.6%p |

### 2. Temperature/TopP는 무관
instructor 구조화 출력에서 sampling 파라미터가 accuracy에 영향 없음 (±0.02 범위).
→ 구조화 출력이 출력 공간을 제한하기 때문.

### 3. v3 프롬프트의 정확도 역설
fewshot_v3 (74.2%) < fewshot_v2 (88.2%)
→ v3의 expanded detection rules가 false positive 증가
→ 하지만 v3가 더 포괄적 감지 (patent, ORCID 등)

### 4. max_tokens=2048 필수
1024에서 응답 잘림 발생 → 2048로 설정.

## Recommendation
- **기본**: fewshot_v2 (최고 accuracy)
- **포괄 감지 필요시**: fewshot_v3 (더 넓은 범위)
- **Sampling**: temp=0.6, top_p=0.75, max_tokens=2048
