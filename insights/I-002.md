# I-002: Parameter Tuning Analysis

## Summary
Optuna TPE 22_trials 수렴 — **temperature/top_p가 structured output에서 무의미**.

## Key Insights

### 1. Sampling 파라미터 무관
| Parameter | Best | Range Tested | Impact |
|---|---|---|---|
| Temperature | 0.6 | 0.0 ~ 1.0 | ±0.02 |
| Top P | 0.75 | 0.7 ~ 1.0 | ±0.02 |
| Max tokens | 2048 | 1024, 2048 | **크게 영향** |

### 2. Why insensitive?
instructor가 Pydantic schema로 출력을 강제 → sampling 공간이 제한됨.
Temperature가 높아도 schema를 벗어나지 못함.

### 3. Max tokens만 영향
1024 → 2048: truncation 해결, accuracy 안정.

## Recommendation
| Parameter | Value | Rationale |
|---|---|---|
| Temperature | 0.2 | 안정성 (동일 입력 → 동일 출력) |
| Top P | 1.0 | 무의미하므로 기본값 |
| Max tokens | 2048 | truncation 방지 |
