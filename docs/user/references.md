# References

This page is the approved reference set for Privacy Router documentation and the course-paper draft. It contains only the eight sources currently cleared for use.

## Approved Sources

1. Helen Nissenbaum. “Privacy as Contextual Integrity.” *Washington Law Review*, 79(1):119–158, 2004. <https://digitalcommons.law.uw.edu/wlr/vol79/iss1/10/>
   - Use for the recipient-, purpose-, and context-dependent account of appropriate information flow.

2. Xinyue Huang, Xiaochun Cao, and Wenyuan Yang. “Need to Know: Contextual-Integrity-Grounded Query Rewriting for Privacy-Conscious LLM Delegation.” arXiv:2606.04067, 2026. <https://arxiv.org/abs/2606.04067>
   - Use for necessity-based minimization in delegated language-model requests.

3. Shijing Hu, Liang Liu, Zhu Meng, and Zhicheng Zhao. “ToolPrivacyBench: Benchmarking Purpose-Bound Privacy in Tool-Using LLM Agents.” arXiv:2606.28061, 2026. <https://arxiv.org/abs/2606.28061>
   - Use for purpose-bound privacy evaluation across agents, tools, and backend records.

4. OpenAI. “OpenAI Privacy Filter.” Official Hugging Face model artifact, revision `7ffa9a043d54d1be65afb281eddf0ffbe629385b`, 2026. <https://huggingface.co/openai/privacy-filter/tree/7ffa9a043d54d1be65afb281eddf0ffbe629385b>
   - Use as a pinned fixed-category token-classification baseline. Treat it as a model artifact, not a peer-reviewed paper.

5. Mariia Ponomarenko, Sepideh Abedini, Masoumeh Shafieinejad, D. B. Emerson, Shubhankar Mohapatra, and Xi He. “CAPID: Context-Aware PII Detection for Question-Answering Systems.” arXiv:2602.10074, 2026. <https://arxiv.org/abs/2602.10074>
   - Use as the closest comparison for joint PII span, type, and task-relevance prediction.

6. Justice Owusu Agyemang, Jerry John Kponyo, Elliot Amponsah, Godfred Manu Addo Boakye, and Kwame Opuni-Boachie Obour Agyekum. “LLM-Redactor: An Empirical Evaluation of Eight Techniques for Privacy-Preserving LLM Requests.” arXiv:2604.12064, 2026. <https://arxiv.org/abs/2604.12064>
   - Use for redaction, typed placeholders, reverse mapping, and exact restoration.

7. Shouju Wang, Fenglin Yu, Xirui Liu, Xiaoting Qin, Jue Zhang, Qingwei Lin, Dongmei Zhang, and Saravan Rajmohan. “Privacy in Action: Towards Realistic Privacy Mitigation and Evaluation for LLM-Powered Agents.” *Findings of EMNLP 2025*, pp. 17055–17074, 2025. <https://doi.org/10.18653/v1/2025.findings-emnlp.925>
   - Use for end-to-end privacy mitigation and evaluation in dynamic agent settings.

8. Matt Gardner et al. “Evaluating Models’ Local Decision Boundaries via Contrast Sets.” *Findings of EMNLP 2020*, pp. 1307–1323, 2020. <https://doi.org/10.18653/v1/2020.findings-emnlp.117>
   - Use for controlled context pairs that change one recipient, purpose, or permission condition at a time.

## Citation Rule

Do not add a source to project prose solely because it is topically similar. Verify its title, authorship, publication status, stable locator, and the exact claim it supports before adding it to this approved set.
