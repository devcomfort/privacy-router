Privacy Router 로컬 검사 도구

정보 항목별 기밀성과 작업 필수성을 확인하고, 마스킹 전후를 비교합니다.

모델 연결 정보 불러오는 중

입력은 로컬 서버와 연결된 피어 모델에서 처리됩니다. 외부 서비스로 전송하거나 브라우저 저장소에 보관하지 않습니다. 라우터는 처리 단계와 권장 행동을 제공하며, 이 데모는 답변 생성이나 이메일·문자 발송을 하지 않습니다.
도구를 준비하고 있습니다. 아직 모델을 호출하지 않았습니다.

합성 예제로 시작

예제를 고르면 입력만 바뀝니다. 검사는 실행 버튼을 눌러 시작합니다.

예시의 예상 결과는 설명용입니다. 실제 모델의 검출 결과와 다를 수 있습니다.

위에서 아래로 대화 순서입니다. 이전 메시지도 현재 메시지와 함께 검사합니다.

최대 12개 메시지 · 전체 16,000자. 입력만으로는 모델을 호출하지 않습니다.

첫 실행은 의도 분석 후 공개·비공개 정보 항목을 추출합니다. 같은 입력을 다시 실행하면 메모리에만 보관한 의도를 보내 실제 추출 캐시를 확인합니다. 서버 캐시에는 해시·위치·판정 메타데이터만 남고 원문·의도·근거 문장은 저장하지 않습니다. 이전 설명은 입력·의도·판정이 같을 때만 이 브라우저 메모리에서 다시 표시하며, 입력 수정·초기화·오류 시 지웁니다.

    검사 결과가 여기에 표시됩니다

    예제를 선택하거나 텍스트를 입력한 뒤 검사 실행을 누르세요. 실제 처리 단계, 분석된 의도, 각 정보 항목의 기밀성·필수성과 근거, 권장 행동, 마스킹 결과를 확인할 수 있습니다.

    검사 상태와 권장 행동은 별개입니다. 근거가 부족하면 행동 권고를 보류하며 외부 전달은 차단합니다.

    분석된 작업 의도

    원문에 연결된 어노테이션을 추출의 근거로 사용합니다. 의도나 작업에 값이 필요하다는 판단은 공개·전송 허가가 아닙니다.

    아래는 선택 가능한 행동의 설명입니다. 이번 검사 결과는 위에 표시됩니다.

      원문과 정보 항목

      공개 정보도 포함한 전체 세션의 정보 항목입니다. 기밀성과 작업 필수성은 별도 판단이며, 판단할 수 없으면 해당 축만 미판정으로 표시합니다. 공개 정보는 마스킹하지 않고 비공개·기밀성 미판정 정보는 보호합니다. 겹치는 위치에서는 비공개 보호가 우선합니다.

      • 공개 · 점선 밑줄
      • 비공개 · 이중 밑줄
      • 기밀성 미판정 · 파선 밑줄

      비공개·기밀성 미판정 값은 마스킹과 동일하게 반복 위치까지 강조합니다. 공개 값은 반환된 위치만 강조합니다. 반복 강조는 새 판정이 아니며, 아래 항목에는 추출기가 반환한 위치와 판단 근거를 표시합니다. 위치는 Unicode 코드 포인트 기준 [시작, 끝)입니다.
