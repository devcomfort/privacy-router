# P-E4B-002: Optuna Parameter Tuning (E4B)

## Goal
fewshot_v2 프롬프트에서 temperature/top_p/max_tokens 최적 조합 탐색

## Model
- E4B (google/gemma-4-E4B-it)

## Variables
| Variable | Range | Type |
|---|---|---|
| Temperature | 0.0 ~ 1.0 | Continuous |
| Top P | 0.7 ~ 1.0 | Continuous |
| Max tokens | 1024, 2048 | Categorical |

## Constants
| Constant | Value |
|---|---|
| Prompt | fewshot_v2 |
| Dataset | benchmark_v2.json (120 cases, N=10 subset per trial) |
| vLLM | gpu=0.75, len=4096, MRv2 |
| Concurrency | 8 |

## Method
- Optuna TPE sampler, 50 trials
- N=10 cases per trial (quick eval)
- Objective: weighted score (overall 60% + morph 20% + ctx 20%)

## Hypothesis
- Temperature affects output consistency
- Max tokens=1024 may truncate responses
